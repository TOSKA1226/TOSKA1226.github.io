免费静态站的边界在哪里

免费、快、不用运维，但它有明确的形状。先认清哪三件事它做不了，再决定要不要用它。

  • 发布 2026-08-03
  • 阅读 约 6 分钟
  • 标签 静态站 · 部署 · 成本

先划清楚：静态站能做什么

  • 页面、样式、脚本、JSON 数据文件——凡是构建时能确定的东西。
  • 自动签发的 HTTPS 证书、全球 CDN、每次推送的预览地址。
  • 表单：交给第三方服务，或者干脆用 mailto 链接，不装表单也能收信。
  • 统计：Cloudflare Web Analytics 免费、无 Cookie、不需要埋同意横幅。

这些能力加起来，已经足够撑起一个个人简介加信息源的站点，成本是零。

再划清楚：它做不了什么

需求为什么做不了替代做法
写操作（评论、点赞、收藏）没有后端，没有可写文件系统接第三方评论服务，或者不做
私密内容部署即公开，URL 猜不到不等于安全放在需要登录的地方
实时更新没有数据库，只有构建产物定时构建，或者前端轮询一个 JSON
用户上传没有落盘位置对象存储 + 预签名 URL
定时任务构建钩子能定时构建，不能跑后台逻辑外部 cron 触发构建

这张表最有用的一列是第三列。大多数「静态站做不了」的需求，其实是被误判的——不需要自己写后端，只是需要一个别人写好的服务。

免费额度：实测数字

平台带宽构建其他限制
Cloudflare Pages不限500 次/月（全账号共享）单站 2 万文件，单文件 25MB
GitHub Pages约 100GB/月10 次/小时仓库 1GB，站点建议 1GB 内
Netlify100GB/月，超了停300 分钟/月超限是硬停，不是限速
Vercel Hobby100GB/月—仅限个人非商用

个人站的实际流量通常每月几 GB，四家都够。真正的差别在「超限之后怎么办」：Cloudflare 不限带宽，最差是被要求优化；Netlify 是直接停站。选平台时看这条比看额度数字有用。

国内访问这件事

Cloudflare 的节点在境外，国内打开通常是能开、但不算快。如果要求国内速度，就要绑境内的对象存储或 CDN，而那就必须做 ICP 备案，同时域名还要实名。

免费、国内稳定、不备案——三个条件里只能同时满足两个。先想清楚放弃哪一个，再动手选平台。

什么时候该放弃静态

出现下面任意一个信号，就该考虑换形态了：

  • 需要登录：一旦有「不同人看到不同内容」，静态就到底了。
  • 需要写入：用户产生的数据必须能落盘。
  • 内容多到手工维护不动：几百条以上还靠手改 HTML，说明该上生成器了——注意是生成器，不是后端。

在那之前，一个 JSON 文件就是数据库，git push 就是发布流程，改一条数据不需要重启任何东西。

静态站不是「简陋版的动态站」，它是另一种形状：内容不多、更新不快、读者不少、成本接近零。接受这个形状，它就很够用；不接受，就会一直觉得别扭。
